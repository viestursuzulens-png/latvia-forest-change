# latvia-forest-change
Tracking forest clearcuts in Latvia with satellite images. This is a computer vision learning project. Used data from Sentinel satellite (https://browser.dataspace.copernicus.eu). Vegetation index (used to track clearcuts) calculated using near-infrared and red light reflection.
Most code is generated by Claude, typed by me and line-by-line explanation provided by Claude. For the second learning project I will abandon this approach because I understood that I could re-create very little from memory.
